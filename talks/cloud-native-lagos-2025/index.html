Practical migration strategies ahead of the Ingress-NGINX retirement

A virtual technical session

Date
19 December 2025
Format
Virtual technical session
Audience
75 participants
Status
Delivered

Abstract

A practical session for teams whose Kubernetes clusters depend on the community Ingress-NGINX controller, which is being retired.

We looked at what it takes to replace existing ingress setups, how to weigh the alternatives, and how to plan the move without disturbing production traffic.

Technical topics

  • Kubernetes Ingress
  • Ingress-NGINX retirement
  • Gateway API
  • Migration planning
  • Kubernetes networking
  • Compatibility and configuration changes
  • Production traffic management
  • Reducing migration risk
